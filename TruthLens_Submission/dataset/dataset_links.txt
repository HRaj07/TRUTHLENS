# TruthLens Dataset Download Links

Due to the large size of the datasets (>1GB total), they are not included directly in this folder. Please download them from the following sources:

### 1. FER-2013 (Facial Expression Recognition)
- **Source**: Kaggle
- **Link**: https://www.kaggle.com/datasets/msambare/fer2013
- **Description**: 35,887 grayscale images of 48x48 pixel resolution.

### 2. RAF-DB (Real-world Affective Faces Database)
- **Source**: Official Site
- **Link**: http://www.whdeng.cn/RAF/model1.html
- **Note**: Requires requesting access, or you can find public mirrors on Kaggle.

### 3. CK+ (Extended Cohn-Kanade Dataset)
- **Source**: Kaggle
- **Link**: https://www.kaggle.com/datasets/shawon10/ckplus
- **Description**: Small but high-quality dataset for facial expression analysis.

### 4. RAVDESS (The Ryerson Audio-Visual Database of Emotional Speech and Song)
- **Source**: Zenodo
- **Link**: https://zenodo.org/records/1188976
- **Files needed**: `Video_Speech_Actor_01.zip` (and other actor zips for full training).

---
**Setup Instructions**:
1. Create a `data/` folder in the project root.
2. Extract the datasets into `data/fer2013`, `data/rafdb`, `data/ckplus`, and `data/video_datasets` respectively.
3. Use `prepare_data.py` or the provided training scripts to process the raw files.
